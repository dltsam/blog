# 纸边集 · 个人博客 Demo

一个基于 Jekyll 和 GitHub Pages 的中文博客起始站。文章使用 Markdown 编写，提交到 main 分支后由 GitHub Pages 自动构建和发布。

## 页面

- 首页：博客介绍、置顶文章、最近文章和本地搜索
- 文章归档：按年份浏览，支持标题、摘要和主题搜索
- 关于：可替换的示例作者介绍
- 每篇文章：独立阅读页
- RSS：/feed.xml

## 改成自己的博客

先改 _config.yml 里的标题、简介和站点 URL，再替换 about.md 中的示例介绍、删除或改写 _posts 中的示例文章。发布前请替换示例邮箱。
